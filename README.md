
# 🎬 Netflix Clone App

A modern and responsive Netflix Clone built using Antigravity AI as part of the AI-Driven Software Development Internship.

## 🚀 Features

- Netflix-style user interface
- Responsive design for mobile & desktop
- Interactive navigation bar
- Movie banners and thumbnails
- Multiple movie categories/sections
- Smooth and clean UI experience

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Antigravity AI
